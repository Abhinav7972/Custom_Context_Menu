# Custom Context Menu

A simple front-end project that demonstrates a custom context menu triggered by text selection. The menu appears when the user right-clicks on selected text and provides quick actions such as sharing the selection.

## Features

- Shows a custom context menu when text is selected
- Positions the menu at the cursor location
- Hides automatically when the user clicks elsewhere
- Uses plain HTML, CSS, and JavaScript only
- Easy to extend with additional actions

## Project Structure

- `index.html` – page structure and menu markup
- `style.css` – menu styling and layout
- `script.js` – selection detection and context menu behavior

## How to Run

1. Open `index.html` in a browser.
2. Highlight some text on the page.
3. Right-click to open the custom context menu.
4. Click the menu item or click elsewhere to close it.

## Example Behavior

When text is selected, the menu appears at the pointer position and the selected text can be used in actions such as sharing. If no text is selected, the menu stays hidden.

## Notes

This project is a beginner-friendly exercise for learning DOM events, selection handling, and custom UI interactions in JavaScript.
